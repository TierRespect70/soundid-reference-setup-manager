## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Calibration Library** | Save and label SoundID monitor calibration profiles |
| **Room Notes** | Document room acoustic treatment and measurement session notes |
| **Headphone Profiles** | Track headphone calibration files and firmware version info |
| **Setup Log** | Log monitoring setup changes and their effect on mixing reference |
